pg_tokenizer 1.2.0 updates pgrx to 0.20.0 and supports PostgreSQL 15–19.

- Add PostgreSQL 19 to the test and package matrices.
- Require Rust 1.99.1 or later and matching Clang, libclang, and LLVM tools.
- Restore the caller memory context before cleaning up a failed trigger assignment, so domain and length errors return normally.
- Preserve SQL APIs, catalog data, tokenizer definitions, and vocabulary token IDs when upgrading from 1.1.0.

Install the matching package, restart PostgreSQL, and run `ALTER EXTENSION pg_tokenizer UPDATE;` in each database. Deploy the matching library to replicas and restart them as well. No token regeneration is required for the 1.1.0 → 1.2.0 upgrade.

PostgreSQL 14 is no longer supported by pgrx. Upgrade PostgreSQL before installing this release. For migrations from earlier extension versions, follow the [installation guide](../01-installation.md#upgrading).
